# Play の画面づくり: MFM でレイアウトを崩さない・重ねる・動かす

Misskey Play で、ゲームのように画面が切り替わる Play を作るときの知見をまとめます。
この資料は、Misskey 本体のソース（`packages/frontend-shared/js/mfm-renderer.ts` など）を読み、この playground と Misskey の画面で確かめた結果です。
playground の MFM の描画（mfm-renderer v0.4.0 以降）は、ここに書いた本体の描き方に合わせてあります。

## 1. Misskey は MFM の関数をどう描くか

### 関数ごとに inline-block の span で包む

`$[名前 中身]` のうち style を持つ関数は、`<span style="display: inline-block; …">中身</span>` のように包まれます。
そのため、`$[bg.color=000 $[fg.color=fff 1 行目{改行}2 行目]]` は、背景の付いた 1 つの四角になります。`$[border]` と組み合わせると、枠付きのウィンドウになります。

### 場所を取るかどうか

関数によって、周りの文字を押し出すもの（場所を取るもの）と、見た目だけを変えるものがあります。画面の高さを保ちたいときは、見た目だけを変える関数を使います。

| 関数 | 場所 | 中身 |
| --- | --- | --- |
| `x2` `x3` `x4` | 取る | 文字の大きさを 200%・400%・600% にする |
| `tada` | 取る | 文字の大きさを **150%** にしたうえで動かす。並べたマスに使うと、その段だけ幅が広がってずれる |
| `scale` | 取らない | `transform: scale()`。x と y は **5 まで**（それより大きい値は 5 になる） |
| `position` | 取らない | `transform: translate(…em)`。**上限はない**（MFM アートでは ±9950 なども使われている） |
| `rotate` `flip` | 取らない | 回転・反転 |
| `spin` `jump` `bounce` `shake` `twitch` `jelly` `rainbow` `sparkle` | 取らない | アニメーション |
| `fg` `bg` `border` `blur` | 取らない | 色・枠・ぼかし |

### 色と枠

- **色の書き方:** `fg` と `bg` の色は、3・4・6 桁の 16 進数で書きます。4 桁にすると、最後の桁が透明度になります（`0000` は透明、`8888` は半透明の灰色）。それ以外の書き方は、赤（`f00`）になります。`000000cc` のような 8 桁も赤になります。
- **border の引数:** `$[border.width=2,color=fff,radius=6,style=solid …]` のように書きます。既定値は次のとおりです。
  - `width`: 1（px）
  - `style`: solid（ほかに dotted・dashed・double・groove・ridge・inset・outset・hidden）
  - `radius`: 0（px）
  - `color`: テーマのアクセント色
- **border のクリップ:** 中身が枠からはみ出すと、はみ出した部分は切り取られます。`noclip` を付けると切り取りません。

### そのほかの決まり

- **入れ子の上限:** 入れ子は 20 段までです。20 段目は文字のまま出ます。`$[ ]` に加えて、`<center>` や `**` などもすべて数えます。
- **`<center>` の書き方:** `<center>` は行の頭に置いたときだけ効きます。中身が空の `<center></center>` は、タグが文字のまま出ます。
- **カスタム絵文字の高さ:** カスタム絵文字は高さ 2em、普通の絵文字（Twemoji）は 1.25em で描かれます。カスタム絵文字を含む行だけ背が高くなります。
- **設定による違い:** 見る人の設定で、効かない関数があります。
  - `position`・`scale`・`x2`〜`x4` は、「高度なMFMを有効にする」がオフだと効きません。
  - アニメーションは、「動きのあるMFMを有効にする」がオフだと動きません。

  演出に頼るゲームでは、タイトル画面に「これが動いていなければ設定を確かめて」という案内を出すとよいです。設定名は Misskey 本体の表記のまま書きます。

```
$[spin.speed=2s ⭐] $[scale.x=1.6,y=1.6 💥] が 動かない・大きくないときは
設定の「動きのあるMFMを有効にする」と
「高度なMFMを有効にする」を オンに してね
```

## 2. 高さを固定して、操作する部品を動かさない

画面が切り替わるたびにボタンの位置が変わると、スマホで押し間違えます。押す部品より上にあるものの高さを、どの場面でも同じにします。

### 十字キーは MFM で作る

- **ボタンを使わない理由:** Misskey のボタン（`Ui:C:buttons`）は幅に下限があります。スマホでは、3 つ並べると折り返します。十字キーは、MFM の絵文字を `$[clickable]` でタップさせて作ります。
- **A・B ボタン:** A と B を足せば、メニュー・メッセージ送り・戦闘まで、6 つのボタンだけで操作できます。
- **すき間の詰め物:** すき間には、同じ絵文字を 0 倍に縮めた見えない詰め物を置きます。`scale` は見た目しか変えないので、幅はそのまま残ります。画面の外へ動かす `position` でも隠せますが、`<center>` の中では環境によってずれることがあります。

```
let gap = "$[scale.x=0,y=0 ⬛]"
let key = @(k, emoji) { `$[clickable.ev={k} {emoji}]` }
Ui:C:mfm({
	text: `<center>$[x2 {gap}{key("u", "⬆️")}{gap}{gap}{gap}{key("a", "🅰️")}]{Str:lf}$[x2 {key("l", "⬅️")}{key("d", "⬇️")}{key("r", "➡️")}{gap}{key("b", "🅱️")}{gap}]</center>`,
	size: 1.3,
	onClickEv: @(ev) { press(ev) },
}, "pad")
```

- メニューのカーソルの位置合わせにも、同じ詰め物が使えます（▶ のない行の頭に、0 倍の ▶ を置く）。

### 場面が変わっても高さを変えない

- **大きく見せたい絵:** 大きく見せたい絵（戦闘の敵など）は、`$[x3]` ではなく `$[scale.x=2.6,y=2.6 🐺]` で 1 マスに置きます。フィールドの地図と同じ 9×7 マスの中に敵を置けば、戦闘とフィールドで画面の高さがそろいます。
- **行の固定:** メッセージやメニューの欄は、いつも同じ行数にします。足りない行は `"　"` で埋めます。
- **長い文章:** 長い文章は自分で折り返し、ページに分けます。幅は、全角 2・半角 1・絵文字 2.5 くらいで数えると近くなります。`$[…]`・`**…**`・`:カスタム絵文字:` の途中では折り返さないでください（書式が壊れます）。
- **カスタム絵文字を避ける:** 行の高さを固定したい欄には、カスタム絵文字を入れません（1 行だけ高くなります）。登場人物のアイコンがカスタム絵文字なら、その欄だけ普通の絵文字に置き換えます。
- **本番用と playground 用のアイコン:** playground にはサーバーのカスタム絵文字がないので、`:名前:` が文字のまま出ます。登場人物ごとに、本番用（`icon`）と playground 用（`pgIcon`）の両方を書いておき、`if exists PLAYGROUND { … }` の中でだけ差し替えると、どちらでも見られます。アイコンをセーブに保存しているなら、読み込むときに、いまの登場人物から取り直してください（本番と playground でセーブを使い回すと、古いアイコンが残ります）。

```
let CAST = { hero: { name: "ぶろきゃ", icon: ":blobcat_3c:", pgIcon: "😺" } }
if exists PLAYGROUND {
	each let k, Obj:keys(CAST) { if CAST[k].pgIcon != null CAST[k].icon = CAST[k].pgIcon }
}
```
- **長さの変わるもの:** ログのように長さの変わるものは、いちばん下に置きます。

## 3. 重ねる（レイヤーウィンドウ）

`position` は見た目だけを動かすので、動かした要素の元の場所は空いたまま残ります。重ねるときは、**元の場所をどこに置くか**を決めます。

### 押す部品より下に元の場所を置く

1. 重ねたいウィンドウを、十字キーより下の部品（MFM 1 つ）に置く。
2. そこから、重ねたい場所（地図の左上など）まで、`position.y` で持ち上げる。
3. 十字キーまでの高さはすべて固定なので、持ち上げる量はいつも同じになる。
4. ウィンドウを出さないときは、文字を `""` にする。そうすれば場所を取らず、十字キーより下の部品が上に詰まるだけで済む。

```
// lines を 枠付きの 黒い ウィンドウに して、右へ x、下へ lift（em）動かす
@layerWin(lines, x, lift) {
	if lines.len == 0 return ""
	`$[position.x={x},y={lift} $[border.color=fff,width=2,radius=6 $[bg.color=000 $[fg.color=fff 　{lines.join(`　{Str:lf}　`)}　]]]]`
}
```

- **em の基準:** 持ち上げる量の em は、その MFM の文字の大きさが基準です。`Ui:C:mfm` の `size` を 0.9 にしていれば、その 0.9 倍の大きさで 1em になります。
- **量の決め方:** 量は、playground で一度 `y=0` で置き、ブラウザで両方の要素の `getBoundingClientRect()` を測って決めます。
- **本体の文字の大きさと行の高さ:** Misskey 本体の文字の大きさは 14px（設定で 15・16・17px）、行の高さは 1.35 です。playground のプレビューも行の高さを 1.35 にしてあります。持ち上げる量を em で書いておけば、文字の大きさの設定が違っても、ほぼ同じ位置に重なります（部品のあいだの 12px の隙間や枠の太さは px なので、その分だけ数ピクセルずれる）。
- **環境による誤差:** それでも、端末のフォントによって数ピクセルずれることがあります。重ねる先は、多少ずれても困らない場所（地図の上など）にします。実機のスクリーンショットをもらえれば、ずれた量から直せます。
- **重なりの順:** `transform` の付いた要素は、付いていない要素より手前に描かれます。`transform` の付いたものどうしでは、後に書いたものが手前になります。
- **はみ出しの切り取り:** Misskey の `Ui:C:container` は、はみ出しを切り取りません。部品をまたいで重ねられます。

### マスの上に重ねる（マスの数を変えない）

絵文字を並べた盤面で、あるマスの上に演出を重ねたいとき、演出用の要素を足すと、その段のマスが 1 つ増えてずれます。
**隣のマスを演出に置き換え、1 マスぶん戻して重ねます。** 普通の絵文字 1 つの幅は 1.25em です。

```
grid[3][x + 1] = `$[position.x=-1.25 {演出}]`
```

## 4. 演出

- **繰り返しへの対処:** MFM のアニメーションは止まらずに繰り返します。1 回だけ見せたい演出は、メッセージを 1 ページ送るあいだだけ文字に入れ、次の更新で外します。
- **場所を取らない形:** 演出は、場所を取らない関数で作ります（`tada` は場所を取るので、マスの上では使わない）。

| 演出 | 書き方の例 |
| --- | --- |
| 斬撃 | `$[rotate.deg=-40 $[spin.x,speed=.15s $[scale.x=3,y=.14 ⬜]]]`（白い四角を細長くして斜めに置き、spin.x でひらめかせる） |
| 爆発 | `$[scale.x=2.4,y=2.4 $[jelly.speed=.4s $[spin.speed=1.5s 💥]]]` |
| 画面の揺れ（小さく） | `$[scale.x=.25,y=.25 $[twitch.speed=.3s $[scale.x=4,y=4 画面]]]`（4 倍にしてから揺らし、4 分の 1 に戻すと、揺れ幅が 4 分の 1 になる） |
| 点滅（出たり消えたり） | `$[position.y=-9950 $[spin.speed=2s $[spin.alternate,speed=2s $[position.y=9950 X]]]]`（大きな半径で往復させ、動いているあいだは画面の外にいる） |
| 角度を止める | `$[spin.x,speed=100000s,delay=-87500s X]`（負の delay で回転の途中の角度に止める。台形にゆがめるのに使う） |

ほかの技法は、misskey.io の「MFMアート部」チャンネル（https://misskey.io/channels/8gepazrpag ）にあります。ピン留めのノートに技法の解説、概要のリンクに MFM のチートシートがあります。

## 5. 確かめ方

- **位置が動かないか:** 押す部品の位置が動かないかは、`window.__playground` で場面を進めながら、`document.querySelector('[data-as-id="pad"]').getBoundingClientRect().y` を測って比べます（[browser-api.md](browser-api.md)）。
- **途中の場面から始める:** 途中の場面（町の中、戦闘の直前など）から確かめるときは、`storage.set` でセーブを書き換えてから「つづきから」を選びます。
- **アニメーション:** アニメーションは、止めたスクリーンショットでは分かりません。0.1 秒より細かい間隔で連続して撮り、コマを並べるか、GIF にして確かめます。
- **幅の測り方:** 盤面の幅が変わっていないかは、背景のマス（たとえば ⬛）の `getBoundingClientRect().x` を段ごとに比べます。要素全体の大きさを測ると、`scale` や `position` で動かした見た目の大きさまで含まれてしまいます。
